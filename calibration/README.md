# Calibration data

Real calibration datasets live in folders here, such as `calibration/pilot-2027-a/`. Everything in this folder except this README is git-ignored, so personal data never reaches the repository, and the tool refuses real data in any folder git could commit.

Start with [the runbook](../docs/CALIBRATION_RUNBOOK.md). Blank sheets and checklists are in [`docs/calibration/`](../docs/calibration/).

This folder holds no adviser marks and no results. The old `file,score` sheet is no longer read.
